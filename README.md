# Информационная система «Страховая компания»

Курсовой проект по МДК 05.02. Проект включает настольное WPF-приложение, ASP.NET Core Web API и SQL-скрипт развёртывания базы данных.

## Состав проекта

- `01_Пояснительная_записка` — пояснительная записка;
- `02_WPF_Приложение` — настольное приложение на C# WPF;
- `03_API` — ASP.NET Core Web API на .NET 8 со Swagger и JWT;
- `04_Презентация_и_доклад` — презентация и доклад к защите;
- `05_База_данных` — скрипт создания базы, таблиц, связей и тестовых данных.

## Возможности WPF-приложения

- вход администратора;
- просмотр и поиск клиентов;
- добавление, изменение и удаление клиентов;
- оформление договоров страхования;
- просмотр и удаление договоров;
- регистрация страховых случаев;
- контроль суммы страховой выплаты.

## Быстрый запуск базы данных

1. Открыть `05_База_данных/01_Создание_БД_и_таблиц.sql` в SQL Server Management Studio.
2. Выполнить скрипт.
3. Проверить подключение в `DatabaseHelper.cs` и `appsettings.json`.

Учебная учётная запись: `admin` / `123`.

## Запуск API

Из папки `03_API/InsuranceApi`:

```powershell
dotnet restore
dotnet build
dotnet run
```

Swagger: `https://localhost:7001/swagger` или адрес, который покажет консоль.

## Запуск WPF-приложения

Открыть `02_WPF_Приложение/InsuranceApp/InsuranceApp.sln` в Visual Studio 2022, восстановить NuGet-пакеты и запустить проект `InsuranceApp`.
